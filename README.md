# Object-Oriented Programming II — C++

A collection of C++ exercises covering core and intermediate **object-oriented programming** principles.

## Topics Covered
- Encapsulation
- Getters and setters
- Inheritance
- Polymorphism
- Virtual functions
- Pure virtual functions
- Virtual destructors
- `final` functions and classes
- Dynamic object allocation

## Main Example
The banking exercises use a class hierarchy such as `RekeningBank`, `RekeningSyariah`, `RekeningKonvensional`, and `RekeningPremium` to demonstrate polymorphic behavior.

## Purpose
Developed as undergraduate OOP practice in C++.
